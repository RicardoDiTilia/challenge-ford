# Ford Vision

Aplicativo mobile para o Desafio 2 — Impulsionando o VIN Share na América do Sul.

## Stack
- React Native + Expo (SDK 52)
- Expo Router (file based)
- TypeScript
- Zustand (estado global)
- AsyncStorage (persistência local)

## Perfis
- **Admin / Concessionária** — dashboard de VIN Share por unidade, leads proativos e detalhe de cada concessionária.
- **Cliente** — visão 360 do veículo, alertas de manutenção e histórico de serviços.

## Rodando
```bash
npm install
npm start
```

Use `i` para iOS, `a` para Android ou leia o QR Code no Expo Go.
